- move 3d-cursor to future radial rotation origin
- [v] apply target object scale and move target's pivot to 3d-cursor
- [v] create an empty (at 3d-cursor) and parent empty to target
- [v] add Array modifier to target with [v] object offset
- [v] set empty as object offset
- [v] copy target rotation to empty
- rotate empty on chosen axis until it fits
- increase array count in modifier settings

- * separate active curve to loose splines
- * for each spline 
  - * duplicate active target as new target
  - center target origin and active curve origin
  - move target to active curve
  - parent active curve to target object
  - to target apply scale and copy rotation from active curve
    - to target add array modifier: set type to FIT CURVE and curve to ACTIVE CURVE
    - to target add curve modifier: set curve to ACTIVE CURVE

  будет отображать оси вращений в позиции 3d-курсора,
  а полученные при вращении ось и величина будут подставляться в атрибуты модификатора "Simple Deform";
- для атребута "Origin" создать "Empty", переместить к 3d-курсору и скопировать ему вращение активного обьекта;
- в модалке задать оператор "Alt - Realign Origin (Fix)",
  который при нажатии будет вращать "Origin" по шагам X/Y/Z так:
    шаг 1) нажали F: вращать по X на 90 относительно своей оси,
    шаг 2) нажали F: вращать обратно X на -90 относительно своей оси, вращать по Y на 90 относительно своей оси,
    шаг 3) нажали F: вращать обратно Y на -90 относительно своей оси, вращать по Z на 90 относительно своей оси,
    шаг 4) нажали F: вращать обратно Y на -90 относительно своей оси
    шаг 1) ...
- в модалке задать оператор "C - Consider Mesh Selected",
  который в значении True будет создавай вертексную группу из выбранной геометрии и подставлять ее в атрибут;
- после окончания действия сгибания - применить "Simple Deform", удалить "Empty" и возможную вертексную группу.
