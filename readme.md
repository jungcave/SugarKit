# Sugar Kit

## EN

Sugar Kit is a collection of tools for Blender artists that adds various features, 
aimed to improve Blender workflow.

## Features, setups and hotkeys

v3.0:
- Object Viewport Color Palette Setter & Alpha Toggler
- Object Modifier Setups: Bend, Radial Array
- Mesh Select Along Non-Mainfold & Quad Fill
- Vertex Groups Hotkeys: Rename Active, To Sculpt Face Set, To Paint Select Mask
- Curve Data Props Hotkeys: Extrude, Bevel Mode, Depth Set/Toggle, Fill Caps
- Curve Select Endpoints
- Sculpt Draw Curve Setup
- Sculpt Trim Curve
- Sculpt Loose Part(s): Separate, Join, Remesh
- Paint Gradient Panel Hotkey
- Paint Color Palette
- Active Resource Hotkeys: 
    Create New (Shading), Set Active (Shading), Fake User (Shading),
    Make Single, Close, Remove
