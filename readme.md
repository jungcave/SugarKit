# Sugar Kit

## EN

Sugar Kit is a collection of tools for Blender artists that adds various features, 
aimed to improve Blender workflow.

## Features

V3.1:
- Object Viewport Color Palette Setter & Alpha Toggler
- Object Modifier Setups: Bend, Radial Array
- Mesh Select Along Non-Mainfold & Quad Fill
- Vertex Groups Sugar: Rename Active, To Sculpt Face Set, To Paint Select Mask
- Curve Data Props Sugar: Extrude, Bevel Mode, Depth Set/Toggle, Fill Caps
- Curve Select Endpoints
- Sculpt Draw Curve Setup
- Sculpt Trim Curve
- Sculpt Loose Part(s): Separate, Join, Remesh
- Paint Gradient Panel Sugar
- Paint Color Palette
- Paint Mask Invert
- Active Shading Sugar: Create New, Set Active, Fake User, Make Single (+Img), Close (+Img), Remove (+Img)
